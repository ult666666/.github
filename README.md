# Community health files

Default contributing guide, security policy, support guide, code of conduct, and issue and pull request templates for [@ult666666](https://github.com/ult666666)'s repositories. GitHub applies each file to any of my repositories that doesn't define its own ([how defaults work](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)).

| File | Purpose |
| --- | --- |
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to propose, make and verify a change |
| [SECURITY.md](SECURITY.md) | How to report a vulnerability privately |
| [SUPPORT.md](SUPPORT.md) | Where to ask questions |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Expected behavior in issues and pull requests |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE) | Bug report and feature request forms |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | Pull request checklist |
