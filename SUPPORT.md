# Getting help

1. **Read the README.** Most repositories have a quick start and a limitations section that answer common "does it do X?" questions.
2. **Search existing issues**, open and closed. Your question may already have an answer.
3. **Open an issue.** Use the bug report form for something broken and the feature request form for something missing. For a general question, a blank issue is fine.

Please include the version or commit you are using and the exact commands you ran. Support is best effort.
